# Project Title
* Amazon Call Centre Production Data Analysis
  
# Introduction
This project focuses on analyzing Amazon Call Centre production data to evaluate agent performance, customer satisfaction, and operational efficiency.
The goal is to extract meaningful insights from the dataset to help improve customer service quality, reduce response time, and enhance team productivity through data-driven decisions.
# Domain :E-commerce

* Data Visualization: Matplotlib

# Key Insights 

* Identified top-performing agents based on customer satisfaction scores.

* Analyzed call duration trends and resolution rates.

* Found peak hours and call load distribution for workforce optimization.

* Recommended strategies for reducing call wait times.

# Dataset Description

The dataset contains operational data from Amazon’s customer service call centre, including:

* Agent ID / Name

* Number of Calls Handled

* Average Handling Time (AHT)

* Customer Satisfaction (CSAT) Score

* Call Resolution Rate

* Date and Shift Details
  
# Conclusion

This project demonstrates how data analytics can be used to enhance customer service operations and agent productivity.
By leveraging visualization and performance analysis, it provides actionable insights for improving customer satisfaction and operational excellence.
